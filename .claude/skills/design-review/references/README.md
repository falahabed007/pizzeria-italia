# Referenzen für das Design-Review

Das Review vergleicht eine Site mit **drei bestandenen Referenzen** (Screenshots eigener Seiten, die das Gate
mit PASS durchlaufen haben). Im Kundenpaket sind keine Referenzbilder enthalten — sie stammen aus fremden
Projekten. Lege hier deine eigenen ab, sobald deine erste Seite das Gate bestanden hat:

| Datei | Was sie belegt |
|---|---|
| `pass-<projekt>.jpg` | Hero-Bereich bei 1440 px, JPEG, nur Viewport |

Bis dahin arbeitet das Review mit der Rubrik in `../checklist.md` und den Mustern in `tells.md` allein —
das reicht für ein belastbares Urteil, nur der Vergleich „so sieht PASS aus" fehlt.
